# Nyx Music — Windows updates

This repository distributes signed Windows installers and update manifests for Nyx Music.
Application source code is maintained in a separate private repository.

- **Host**: the PC that runs the Discord bot and the shared player.
- **Invite**: friends who join the host session with their Discord account.

Download the matching installer from the latest release. Future updates are offered inside Nyx.
Installer update signatures are verified by the application. These signatures are separate from Windows Authenticode certificates.

No bot token, Spotify credential or signing private key is distributed here.
